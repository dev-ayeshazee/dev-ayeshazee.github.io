# Ayesha Zargham — Portfolio

Live at [dev-ayeshazee.github.io](https://dev-ayeshazee.github.io/)

Senior Full-Stack / Angular Engineer portfolio. Built with Angular 18 (standalone components, signals) and Tailwind CSS.

## Development

```bash
npm install
npm start
```

Navigate to `http://localhost:4200/`.

## Build

```bash
npm run build
```

Output goes to `dist/portfolio/browser`.

## Deployment

Pushes to `main` are automatically built and deployed to GitHub Pages via the workflow in `.github/workflows/deploy.yml`.
